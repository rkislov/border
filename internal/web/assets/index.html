ПОЛИТИКИ И ДОСТУП

Проверка выбора политики

Проверьте сохранённые настройки текущего тенанта до подключения к оборудованию.

Это проверка выбора политики, а не пробный вход. Пароль, TOTP, сертификат, состояние пользователя и правила доступа здесь не проверяются. RADIUS-пакеты не отправляются, доступ и сессии не создаются. Несохранённые изменения редакторов не учитываются.

МОНИТОРИНГ

Состояние системы

Показатели текущего тенанта с момента запуска его среды. После перезапуска счётчики обнуляются.

Нажмите «Обновить состояние» для загрузки.

Результаты отражают фактические операции, а не постоянную проверку доступности LDAP, SMTP или NAS. Отказ входа может означать неверный пароль. Успешный фоновый проход может не содержать операций.

ЭКСПЛУАТАЦИЯ

Хранение истории

Сроки действуют только в текущем тенанте. По умолчанию автоочистка выключена.

0 — хранить без ограничения. Допустимый срок: от 7 до 3650 дней. После сохранения ненулевого срока старые записи будут удаляться автоматически и безвозвратно.

Сессии очищаются по времени последнего изменения записи, только после Stop или Disconnect-ACK. Активные, потерянные и закрытые по Accounting-On/Off сессии, а также разрешения доступа сохраняются. Минимальные служебные записи защиты от повторов не удаляются.

Не более 500 событий и 200 сессий за минутный проход. Сохранение нулевых сроков останавливает будущую очистку, но не возвращает удалённую историю.

RADIUS ACCOUNTING

Сессии

Все сохранённые сессии текущего тенанта. Интервал обновлений и порог «Связь потеряна» задаются отдельно для каждого NAS (по умолчанию 300 и 900 секунд). Потеря связи не подтверждает отключение.

Трафик — накопленные счётчики NAS за текущее поколение сессии. Без Gigawords видны только 32-битные значения: объём после переполнения не восстанавливается. «Нет данных» означает, что NAS не прислал счётчик.

Автоматический отзыв требует связи с разрешением доступа. Для любого NAS настройте возврат Class из Access-Accept во всех accounting-пакетах. Связь с разрешением не гарантирует поддержку Disconnect устройством: проверяйте ответ NAS. При потере Start без Class сессия может учитываться без автоматического отзыва.

Политики авторизации

Какие проверки личности обязательны до выдачи доступа.

Основная проверка определяется выбранным источником. Проверка устройства требует активной записи MAC из Calling-Station-Id. Для EAP-TLS доступна цепочка сертификат → устройство. MAC можно подменить: это дополнительное ограничение, не независимый криптографический фактор.

Пароль + TOTP передаются через PAP как пароль;otp=123456. TOTP предварительно настраивается в личном кабинете. Цепочки выполняются в одном запросе PAP; отдельный диалог Access-Challenge для OTP не используется.

Политики доступа

Права после успешной авторизации, срок действия и ограничения сессии.

Для MAC-политик указывайте MAC в формате aa:bb:cc:dd:ee:ff. Пустые даты означают отсутствие ограничения по соответствующей границе. Срок сессии не превышает дату окончания политики.

Правила доступа

Меньший приоритет проверяется первым. Первое совпадение определяет результат; без совпадений — отказ. Условия разных полей объединяются через И, значения одного поля — через ИЛИ. При включении правил прежний список разрешённых личностей не используется.

Добавить / изменить правило в черновике

Каждое значение — на отдельной строке. Аудитория: совпадение личности или любой выбранной группы. LDAP-группы доступны только для проверки пароля выбранного домена; используются значения memberOf без отдельного раскрытия вложенных и primary-групп AD. Fingerprint — дополнительный признак, не доказательство личности. Пустые условия не ограничивают доступ, неизвестное значение не совпадает с заданным условием.

Изменения вступают в силу после публикации в разделе «Черновики и публикации». VLAN и сроки берутся из выбранной политики доступа.

Окна обслуживания

Ограничивают ручную публикацию и запуск по расписанию для текущего тенанта. Вне окна задание ждёт, но после предельного срока уже не запускается.

Дни обозначают начало интервала. Если конец раньше начала, окно заканчивается на следующий день. Конец не включается; 24:00 означает конец дня. При увеличении задержки старые задания не продлеваются.

Согласование пакетов

Настройка действует для текущего тенанта. Для включения нужны минимум два активных администратора. Отправитель и все, кто редактировал черновики, не могут согласовать свой пакет. Изменение режима сбрасывает ожидающие и выданные согласования и записывается в журнал.

Публикация изменённой политики требует повторного входа для всех её действующих разрешений. Отзыв выполняется фоновым обработчиком и зависит от поддержки Disconnect на NAS. Сессии без привязки к разрешению автоматически не отключаются. Откат не восстанавливает отозванные сессии.

Удаление через черновик

Объект будет удалён только при публикации. Ссылки на него нужно изменить или удалить в том же пакете. Удаление набора правил возвращает проверку списка личностей; удаление набора NAS возвращает одиночную или прежнюю конфигурацию NAS.

Заявки на согласование

Активные заявки и последние 100 записей истории. Одобрение действительно только для полного пакета с проверенными редакциями черновиков.

История публикаций

Последние 100 изменений сгруппированы по пакетам. Откат создаёт черновики всего пакета: впервые созданные объекты удаляются, удалённые восстанавливаются. Проверка зависимостей обязательна.
