Автоматическое получение и продление серверного HTTPS-сертификата. Домен должен вести на сервер; TCP 80 должен достигать встроенного обработчика HTTP-01.

Политики авторизации

Какие проверки личности обязательны до выдачи доступа.

Пароль + TOTP передаются через PAP как пароль;otp=123456. TOTP предварительно настраивается в личном кабинете. MAC и EAP-TLS не комбинируются с паролем в этой версии.

Политики доступа

Права после успешной авторизации, срок действия и ограничения сессии.

Для MAC-политик указывайте MAC в формате aa:bb:cc:dd:ee:ff. Пустые даты означают отсутствие ограничения по соответствующей границе. Срок сессии не превышает дату окончания политики.

Правила доступа

Меньший приоритет проверяется первым. Первое совпадение определяет результат; без совпадений — отказ. Условия разных полей объединяются через И, значения одного поля — через ИЛИ. При включении правил прежний список разрешённых личностей не используется.

Добавить / изменить правило в черновике

Каждое значение — на отдельной строке. Аудитория: совпадение личности или любой выбранной группы. LDAP-группы доступны только для проверки пароля выбранного домена; используются значения memberOf без отдельного раскрытия вложенных и primary-групп AD. Fingerprint — дополнительный признак, не доказательство личности. Пустые условия не ограничивают доступ, неизвестное значение не совпадает с заданным условием.

Изменения вступают в силу только после «Применить набор правил». VLAN и сроки берутся из выбранной политики доступа.

Локальные группы тенанта

Можно объединять local/логины и домен/логины. Членство назначает администратор этого тенанта.

Тенанты

Отдельные базы данных, администраторы, домены, политики, ключи CA и секреты.

Один IP NAS может принадлежать только одному тенанту на общем UDP-слушателе. При совпадении IP запросы отклоняются.
