# SMS-портал и fingerprint

## Гости

В административной панели задаются HTTPS webhook или Twilio, токен и гостевой VLAN. Токен зашифрован BORDER_MASTER_KEY, GET API не возвращает его. Гостевой доступ выключен по умолчанию, включается отдельно глобально и на NAS. Реальная отправка требует аккаунта провайдера; автоматические тесты используют заглушку и локальный TLS-сервер.

Webhook получает POST JSON с полями to и text и Authorization: Bearer. Редиректы запрещены, сертификат проверяется. Внешний провайдер получает номер телефона и текст SMS.

Публичный URL: --portal-url https://portal.example.org, страница /guest. Доверенный адаптер NAS формирует короткоживущую ссылку функцией guest.SignRedirect; формат подписан HMAC-SHA256 секретом NAS, связан с NAS/MAC/session ID, срок 120 секунд. Этот секрет никогда не передаётся браузеру. Администратор может получить тестовую ссылку через POST /api/guest/link. Готовые адаптеры редиректа RouterOS/Chilli/других устройств пока не включены.

Код действует 5 минут, максимум 5 попыток. Повторная отправка через 60 секунд; максимум 5 отправок на номер и устройство за 15 минут, общий часовой лимит задаётся в панели. Неудачная доставка расходует лимит и аннулирует код. Номер в базе зашифрован, код хранится в HMAC-виде, журнал и список разрешений содержат маску номера. Запросы удаляются через час.

Подтверждение выдаёт ограниченное по времени разрешение MAC на конкретном NAS. Статический запрет MAC имеет приоритет. Для известной активной accounting-сессии возможен CoA; иначе требуется повторная авторизация на NAS. Отзыв разрешения запрещает следующую авторизацию, но не отключает текущую сессию автоматически: используйте Disconnect.

## Fingerprint

Подписанные Access-Request доверенных NAS обновляют MAC, NAS и last-seen. Администратор вводит DHCP option 55 (упорядоченный список), vendor class 60, hostname, ОС, производителя и тип. Эти поля доступны также через административный POST /api/fingerprints с обычной сессией и CSRF.

Автоматический перехват DHCP, удалённые коллекторы и автоматическая классификация ОС пока не реализованы. Fingerprint не предоставляет доступ и не заменяет аутентификацию. Последние 100 административных изменений каждого устройства хранятся в истории.

Справочник OUI заполняется администратором: 6/7/9 шестнадцатеричных цифр для 24/28/36 бит. Выбирается наиболее длинный префикс. Для локальных/рандомизированных MAC производитель по OUI не определяется. Полный внешний справочник производителей не включён. Панель показывает последние 1000 устройств.
